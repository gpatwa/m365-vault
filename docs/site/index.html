Quick Start

Prerequisites

  • Docker + Docker Compose
  • Microsoft 365 tenant with admin access
  • Azure AD App Registration with Graph API permissions

1. Clone and start

git clone https://github.com/gpatwa/m365-vault.git
cd m365-vault
make dev

2. Access the UI

Open http://localhost:5173 and login with admin / admin123

3. Onboard your tenant

Go to Tenants → Add Tenant → Follow the 3-step wizard.

4. Run your first backup

After onboarding, the scheduler automatically runs backups based on your SLA policy. Or trigger an on-demand backup from any workload page.

Data Flow

Microsoft Graph API
    ↓ (backup)
GraphClient (auth, throttling, retry)
    ↓
Worker (Exchange/OneDrive/SharePoint/Teams/EntraID)
    ↓
Compress (zstd) → Dedup (CDC) → Encrypt (AES-256-GCM)
    ↓
Storage Backend (MinIO / Azure Blob / Local)
    ↓
Catalog (PostgreSQL: snapshots, items, metadata)

Local Development

# Start all services
make dev

# Rebuild after code changes
docker compose up -d --build

# View logs
docker compose logs -f backend

# Stop
docker compose down
